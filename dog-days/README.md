# PawPace

PawPace is a Dog Days Weekend Challenge project for DEV. It helps plan safer
dog walks during warm weather by combining temperature, humidity, pavement,
walk length, and dog sensitivity into a readable walk plan.

## Features

- Dog walk caution score.
- Paw/pavement check guidance.
- Hydration and timing recommendations.
- Indoor enrichment backup plan for high-risk weather.
- Optional Google AI mode using a local, user-provided Google AI Studio key.
- CSS dog illustration, responsive layout, keyboard focus states, and
  reduced-motion support.

## Live Demo

https://rohithmatham12.github.io/dev-comfort-food-challenge/dog-days/

## Notes

PawPace is not veterinary advice. It is a frontend decision helper for everyday
walk planning.
